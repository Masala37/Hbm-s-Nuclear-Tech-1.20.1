Hbm's Nuclear Tech · Forge port

ALPHA · 1.0.28 · MC 1.20.1

Nuclear Tech on 1.20.1

Unofficial Forge rewrite of Hbm's Nuclear Tech. Bombs, radiation, Sellafield, and early machines are playable. Most of the legacy catalog is still placeholders — tooltips tell you what works.

Download alpha JAR Source on GitHub Port status

Requirements

  • Minecraft 1.20.1
  • Forge 47.x (built against 47.4.10)
  • Java 17

What to expect

  • Working Nuke lineup, detonators, landmines, charges, bomb caller, radiation / contamination, Sellafield, hazmat, Geiger, missile MVP, early power machines.
  • WIP Missiles beyond generic, RBMK skeleton, many machines and materials — incomplete systems.
  • Not implemented Bulk catalog stubs and most weapons/turrets — placeholders only. Creative tabs are labeled accordingly.

Disclaimer

  • This is an alpha community port — expect bugs, crashes, and missing content.
  • Not affiliated with the original Hbm / Bobcat 1.7.10 releases.
  • Original 1.7.10 source is kept under legacy-1.7.10/ for reference.
